心臓移植 学習ノート：スターター版

このフォルダには、アプリの最初の試作品が入っています。

ファイルの役割
- index.html：画面の構造
- styles.css：色、文字、配置
- app.js：メニュー、用語検索、サンプル問題の動き
- manifest.json：ホーム画面追加用のアプリ情報
- service-worker.js：オフライン用キャッシュの仕組み

まずPCで画面を確認する方法
1. ZIPを解凍します。
2. index.htmlをChromeやEdgeで開きます。
3. メニューをクリックし、用語検索に「タクロリムス」や「DSA」と入力して試します。

注意
- ローカルでHTMLを直接開いた状態では、PWAのインストールやオフライン動作は完全には確認できません。
- iPhoneのホーム画面に追加し、オフラインでも動かすには、HTTPSで配信する場所（例：GitHub Pagesなど）へ公開する設定が必要です。
- このスターター版は学習用の試作品で、医療判断を支援する正式な医療機器・診療支援システムではありません。
- 医療情報を追加するときは、信頼できる出典、改訂日、確認者を記録してください。
- 患者を特定できる情報は入力・保存しないでください。
